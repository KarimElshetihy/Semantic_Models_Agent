# SAMPLE: DAX measure style (NOT APPROVED)

Status: sample text for testing retrieval. Replace it with your team's approved standard.

- Use DIVIDE for ratios so a zero denominator returns BLANK instead of an error.
- Qualify column references with the table name, for example `Sales[Amount]`.
- Avoid whole-column iterators on large tables when a simple aggregation works.
- Put a short comment above any measure whose logic is not obvious from its name.
