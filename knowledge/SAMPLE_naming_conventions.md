# SAMPLE: naming conventions (NOT APPROVED)

Status: sample text for testing retrieval. Replace it with your team's approved standard.

- Table names: singular business nouns in Title Case, for example `Sales Order`.
- Measure names: Title Case with spaces, for example `Total Sales Amount`.
- Ratio measures start with `Pct` when they return a percentage, for example `Pct Margin`.
- Keys and foreign keys end with `Key`, for example `Customer Key`.
- Hidden helper columns start with `_`.
